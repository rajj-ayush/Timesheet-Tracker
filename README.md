# Timesheet Tracker

An automated background activity tracking and timesheet management system built for Hoonartek. It monitors active window durations, syncs logs securely via a cloud API, and generates daily summaries to streamline timesheet filling.

## Features
- **Background Activity Tracker:** Quietly logs active application usage in 30-minute intervals.
- **Secure Architecture:** Decoupled frontend desktop app communicating with a secure backend API.
- **Streamlit Dashboard:** Interactive portal to view daily logs and export summaries.
- **Quick Autofill:** Global shortcut (`Ctrl + Alt + T`) to instantly fetch and copy your daily timesheet summary.
